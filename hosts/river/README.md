# MECHREVO Wujie 14XA (Ryzen 7 8845HS)

## Hardware

- **Model:** MECHREVO WUJIE14XA (WUJIE 14X Blizzard)
- **Motherboard:** WUJIE14-GX4HRXL
- **CPU:** AMD Ryzen 7 8845HS (Phoenix / Hawk Point), 8 cores / 16 threads
- **Memory:** 32 GB (2 × 16 GB) DDR5-5600, Crucial CT16G56C46S5.C8D
- **Storage:** Micron 2550 NVMe SSD, 1 TB (CT1000P3PSSD8)
- **BIOS:** N.1.14MRO50 (2025-11-13)

## BIOS

The BIOS update tool is provided as a Windows `.EXE` file.
